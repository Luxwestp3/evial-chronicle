# Обработка сессий и ведение архива

Базовая структура архива и канонические написания имён — в [content/README.md](../../content/README.md).

## 1. Аудио → транскрипт (гибридный пайплайн)

Оригиналы `.m4a` (48 кГц, 256 кбит/с) не пережимаются в 16 кГц / 64 кбит/с и не грузятся руками в веб-чаты.

1. **Нарезка и WAV для диаризации:**

   ```bash
   scripts/audio/chunk.sh /Users/luxwestps/Documents/Projects/GitHub/Dungeons_Audios/session-NNN/session-NNN.m4a N
   ```

   Режет оригинал на 12-минутные `.mp3` (44.1 кГц, 128 кбит/с, моно) с перекрытием 15 сек в `private/transcripts/session-NNN/chunks/` и готовит `audio-16k.wav` + `chunks.json`.

2. **Локальная диаризация + текстовые якоря (`sherpa-onnx` + `pyannote-segmentation-3.0` + `TitaNet-Large` + `GigaAM-v3-punct`):**

   ```bash
   private/diarizer/.venv/bin/python scripts/audio/diarize.py private/transcripts/session-NNN
   ```

   Кластеризует голоса по всей сессии, сопоставляет кластеры и каждый сегмент с 6 проверенными референсами в `private/voices/`, прогоняет локальный `GigaAM-v3-punct` поверх сегментов (0% квоты API) и генерирует `chunks/chunk-XX.anchored.txt`.

3. **Однопроходная мультимодальная вычитка кусков и склейка:**
   - Лёгкие субагенты `dnd-anchored-transcriber` (`model="flash"`, 4 Hydrogen) за один проход (без shell/ffmpeg) читают `chunk-XX.anchored.txt` и слушают `chunk-XX.mp3`, исправляют лор/термины/перекличку и пишут чистый `chunk-XX.md`.
   - Склейка в единый `private/transcripts/session-NNN/transcript.md`:
     ```bash
     node scripts/audio/merge-chunks.mjs private/transcripts/session-NNN
     ```

## 2. Хроника и стиль

- Формат страницы сессии ([шаблон](templates/session.md)):
  - YAML-шапка с `number`, `date_real`, `day_start`, `day_end`, `date_world`, `location`, `players`, `characters`, `tags`, `sources`.
  - Абзац `**Коротко.**` — один абзац сути (идёт на главную и в ленту хроники).
  - Одна цельная хроника по сценам (`## 1. ...`), **без** отдельной вкладки «Кратко».
  - В конце: `## Итог` (последствия, лут, опыт, точка остановки) и `## Цитаты` (лучшие живые реплики).
- **Слог:** живой, приземлённый, естественный русский пересказ реальной партии — без сухого протокола («Убеждение — 13, Спасбросок — 7») и без напыщенной книжной литературщины с лишними метафорами.
- **Факты и механика:** строго по записи, ничего не додумывать. Цифры и механику (опыт, уровни, подклассы, свойства предметов, криты, смерти) фиксировать там, где они реально важны для сюжета или состояния партии.
- Отделять факт от слуха, плана, шутки за столом и предположения игрока; фиксировать, кто именно присутствовал и знает тайну.

## 3. Обновление архива

1. Написать хронику `content/sessions/NNN-short-title.md`.
2. Обновить затронутые карточки (`characters/pc/`, `characters/npc/`, `places/`, `factions/`, `lore/`, `rules/`). **Не плодить отдельные карточки для одноразовых NPC** — упоминать их в хронике и карточке места/сцены.
3. Обновить сводки: `goals.md`, `threads.md` (сюжетные нити мира), `relationships.md`, `timeline.md`, `questions.md` (только реальные неясности и противоречия).
4. Обновить ссылку на последнюю сессию в [CONTEXT.md](CONTEXT.md).
5. Пересобрать сайт (`node scripts/prepare.mjs && npx quartz build -d .site-content`) и вынести пользователю короткий список спорных мест по итогам сессии.
