# Рабочие и редакторские решения

Этот журнал хранит решения о ведении архива. Факты кампании и ответы на сюжетные вопросы
остаются в [карточках и хрониках](../../content/README.md), а подтверждённые уточнения —
в [разделе «Решено»](../../content/questions.md#решено). Не копируй их сюда.

## 2026-11-15 — переход рабочего процесса на Codex

Основание: поручение владельца репозитория реализовать второй этап миграции в отдельной
ветке и подготовить PR без слияния в `main`.

- `content/` принят основным источником истины. Правила и запрет старого импорта
  закреплены в [AGENTS.md](../../AGENTS.md).
- Постоянный контекст организован как [навигация](CONTEXT.md) по существующему архиву;
  обработка транскриптов описана в [WORKFLOW.md](WORKFLOW.md).
- Изменения этого этапа ограничены инструкциями, служебными документами и шаблонами.
  Корневой README с прежней инструкцией импорта, содержимое кампании, скрипты,
  зависимости и GitHub Pages оставлены без изменений по границам поручения.

## 2026-11-22 — P0: честные доки и даты

Основание: поручение владельца выполнить P0 из [плана](PLAN.md).

- `scripts/sync-archive.sh` удалён, корневой README переписан: `content/` — источник
  истины, импорт из внешнего архива запрещён, команда синхронизации убрана.
- Расшифровки хранятся вне архива, в `private/transcripts/session-NNN/`, и не публикуются.
- Дата последнего коммита больше не выводится на страницах. У сессий показывается
  `date_real` из шапки, у остальных страниц мета скрыта.

## 2026-11-22 — финал транскрипта сессии 3 не считается источником

Транскрипт `session_003_transcript.md` до ~03:07 совпадает с записью по событиям и именам.
Дальше модель дописала финал гладким литературным текстом, и там есть прямые выдумки:

- «она осталась там, в тёмноте саркофага» — хотя в записи Вайсши просыпается, уходит и убивает змею;
- «за скелетов в начале» — скелетов в сессии не было;
- содержимое урн заменено на травы и благовония, хотя в записи там яйца;
- Азгелос назван колдуном, Бабалай — друидом; в архиве Азгелос плут, а покровитель и «Расщепление разума» — у Бабалая;
- точные числа опыта и хитов, которых в записи не разобрать.

Поэтому хвост транскрипта использован только там, где совпадает с whisper
(`full-whisper.md`): завал, пробуждение Азгелоса, дорога к Нарну. Уровень и подклассы
не записаны как канон — они ушли в `content/questions.md`.

## 2026-11-22 — дата сессии 3 из метаданных записи

В `session-003.m4a` стоит `creation_time=2026-11-15T11:39:03Z` при смещении +0300,
то есть 15 ноября 2026, 14:39 по Москве. Имя файла с телефона (`Voice 261115_110705`)
даёт ту же дату, поэтому `date_real` сессии 3 — 15 ноября 2026.

## 2026-11-22 — дата сессии 2 взята из метаданных записи

Основание: в `session-002.m4a` есть `creation_time=2026-11-08T11:59:25Z` при смещении
+0300, то есть 8 ноября 2026, 14:59 по Москве. Дата файла на диске (22 ноября) —
время переноса с телефона, а не игры.

- `date_real` сессии 2 — 8 ноября 2026.
- Смерть и воскрешение Азгелоса записаны как канон по прямой сцене мастера.
  Конкретная раса нового тела остаётся открытым вопросом до ответа мастера.

## Добавление решения

Для нового рабочего или редакторского решения укажи дату, основание (явное поручение,
ссылку на PR/коммит или источник), принятое правило и ссылки на затронутые документы.
Не приписывай мастеру или игрокам решения, которых нет в источниках.
Исправление факта оформляй в архиве, здесь при необходимости оставляй только ссылку.
