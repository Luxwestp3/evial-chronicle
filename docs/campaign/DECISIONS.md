# Рабочие и редакторские решения

Этот журнал хранит решения о ведении архива. Факты кампании и ответы на сюжетные вопросы
остаются в [карточках и хрониках](../../content/README.md), а подтверждённые уточнения —
в [разделе «Решено»](../../content/questions.md#решено). Не копируй их сюда.

## 2026-11-15 — переход рабочего процесса на Codex

Основание: поручение владельца репозитория реализовать второй этап миграции в отдельной
ветке и подготовить PR без слияния в `main`.

- `content/` принят основным источником истины. Правила и запрет старого импорта
  закреплены в [AGENTS.md](../../AGENTS.md).
- Постоянный контекст организован как [навигация](CONTEXT.md) по существующему архиву;
  обработка транскриптов описана в [WORKFLOW.md](WORKFLOW.md).
- Изменения этого этапа ограничены инструкциями, служебными документами и шаблонами.
  Корневой README с прежней инструкцией импорта, содержимое кампании, скрипты,
  зависимости и GitHub Pages оставлены без изменений по границам поручения.

## 2026-11-15 — открытые неясности второй сессии

Основание: уточнение пользователя при подготовке [PR №4](https://github.com/Luxwestp3/evial-chronicle/pull/4): детали нельзя достоверно восстановить по памяти, спорные моменты следует оставить открытыми, сохранив подробный пересказ.

- Противоречия не разрешаются редакторской догадкой. Существенные нерешённые вопросы остаются в [questions.md](../../content/questions.md#сессия-2-для-сверки) до появления подтверждения; ответы уточняются по мере необходимости.
- Восстанавливаемые события сохраняются даже при неясности отдельного имени, расчёта или причины. Предварительная атрибуция явно оговаривается в хронике и связанных записях.
- Новые уточнения вносятся точечно в существующий PR; хроника целиком не переписывается и не сокращается из-за отдельных неясностей.

## Добавление решения

Для нового рабочего или редакторского решения укажи дату, основание (явное поручение,
ссылку на PR/коммит или источник), принятое правило и ссылки на затронутые документы.
Не приписывай мастеру или игрокам решения, которых нет в источниках.
Исправление факта оформляй в архиве, здесь при необходимости оставляй только ссылку.
