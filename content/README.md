# Архив кампании «Расхитители спален»

Мастер: **Вазген**. Система: **D&D 5.5e (правила 2024)** с хоумбрю-правилами.
Время в мире идёт параллельно реальному: сейчас в мире осень, неделя в жизни примерно равна неделе в игре.
Архив ведётся с точки зрения игроков, спойлеры не скрываются.
Тексты хроник и карточек сгенерированы с помощью ИИ по аудиозаписям сессий — в деталях, цитатах и атрибуции реплик возможны неточности.
