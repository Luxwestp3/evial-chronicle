# Архив кампании D&D

Мастер: **Вазген**. Система: **D&D 5.5e (правила 2024)** с большим набором хоумбрю.
Время в мире идёт параллельно реальному: сейчас в мире осень, неделя в жизни примерно равна неделе в игре.
Архив ведётся с точки зрения игроков, спойлеры не скрываются.

|---|---|---|---|---|
| [Каин](characters/pc/kain.md) | Серёжа | человек | плут | найти сестру, о которой узнал из анонимного письма |

| [Хаген Неустанный](characters/pc/hagen.md) | Петя | дварф | варвар | вернуть амулет Гару Неумолимому и выкупить брата |

## Как пополнять архив

1. Расшифровки новой сессии кладутся в `transcripts/session-NNN/`.
2. Хроника пишется в `sessions/NNN-короткое-название.md` по образцу сессии 0.
3. Новые сущности получают свой файл в нужной папке; в YAML-шапке указывается `first_seen: NNN`, верх карточки описывает то, что известно сейчас (переписывается целиком), а в конце ведётся раздел «История»: по строчке на каждую сессию, где о сущности что-то узнали, со ссылкой на сессию.
4. Обновляются [goals.md](goals.md), [relationships.md](relationships.md), [timeline.md](timeline.md) и [questions.md](questions.md).

Файлы называются латиницей (транслит), заголовки и текст по-русски. У каждого файла есть YAML-шапка (`title`, `type`, `tags`, `aliases`, `first_seen`), чтобы потом собрать из архива сайт на GitHub Pages без переделки.

## Написание имён

Расшифровки часто ошибаются в именах. Правильные формы:

| Правильно | Встречается в расшифровках |
|---|---|
| Бабалай | Бабавай |
| Гар Неумолимый | Гард Неумолимый |
| Вазген | Возген |
| империя Эбин | Эбен, Эвен, Эббина, Эдинд, Эвин |
| Железные горы | Железные холмы |
| Мекамп | Викамп, Микап |
| Харр | Хара |
| Саппадор | Салладор |
| Нарн | Марм |
| Семиградье | Семиградия, Семенград |
| Геннадиус | Геннадий |
| Огненный архипелаг | «огненный нашел филарк» и т. п. |
